没有匹配的 Demo，请换一个关键词或选择“全部”。

怎么看：世界视角展示人体与相机的空间关系；“实际相机视角”展示输入相机拍到的画面。

透明导出：RGBA PNG 含真实透明度；MP4 / GIF 使用白底。网页棋盘格只用于查看透明区域。

数据来源：全部人体来自SMPL-H 步行动作，不使用骨架或程序小人。人体网格、世界root与时间保持原样；跟随、固定和环绕相机是明确编写的演示方案，不是生成模型预测。

版本：复用样例保留各自版本和渲染摘要；完整动画与外观图片分别标明，没有为展示重复渲染全部旧样例。
